# Referências das demos

Material bruto de cada ótica (fotos, prints, vídeos), separado do site.

- Este ramo (`referencias`) **não é publicado** na Vercel e nunca se mistura com a `main`.
- Um `.zip` por ótica, com o nome da pasta da demo: `otica-sales.zip`, `otica-der.zip`…
  (a lista está no `README.md` da `main`).
- Pelo navegador, o GitHub aceita arquivos de até 25 MB. Se passar, divida em partes
  (`otica-sales-1.zip`, `otica-sales-2.zip`) ou exporte as fotos em JPG.

Na demo entram só as fotos escolhidas, já dentro do `index.html` da ótica.
